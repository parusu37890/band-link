# 0001: 利用停止中ユーザーの過去メッセージ表示

- 状態: 確定（2026-09-05）
- 関連: requirements.md 3章（閲覧・認証・アカウント）

## 背景

旧要件では退会ユーザーについても会話を残す方針だった。2026-09-07に `docs/decisions/0007` で本人退会時はデータを削除する方針へ変更したため、本決定の表示ルールは運営による利用停止ユーザーに適用する。

## 決定

利用停止中ユーザーの過去メッセージの送信者名は「利用停止中ユーザー」のように状態を示す表示に置き換える。本人退会では会話ごと削除するため、この表示は利用停止にだけ適用する。

## 理由

利用停止はアカウントと会話を保持したまま投稿・メッセージ送信を禁止するため、相手に状態を伝える必要がある。本人退会はデータを削除するため、同じ表示を必要としない。

## 影響

- メッセージ表示コンポーネントは、送信者の`User`の状態（正常/利用停止）を見て表示名を出し分ける必要がある。
- 利用停止が解除された場合は元の表示名に戻る。
