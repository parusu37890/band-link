# 0001: 利用停止中ユーザーの過去メッセージ表示

- 状態: 確定（2026-09-05）
- 関連: requirements.md 3章（閲覧・認証・アカウント）

## 背景

要件定義書は退会ユーザーについて「相手側には送信済み会話を残し、送信者名を『退会済みユーザー』に置き換える」と明記している。一方、利用停止（退会ではない）ユーザーの過去メッセージの送信者名表示は未記載だった。

## 決定

利用停止中ユーザーも、退会ユーザーと同じ表示ルールを適用する。過去メッセージの送信者名は「利用停止中ユーザー」のように状態を示す表示に置き換える。

## 理由

退会・利用停止のどちらも「投稿・メッセージ送信を禁止し、プロフィールを非公開にする」という点で扱いが近い。表示ロジックを1本化することで実装・テストの分岐を減らせる。

## 影響

- メッセージ表示コンポーネントは、送信者の`User`の状態（正常/退会/利用停止）を見て表示名を出し分ける必要がある。
- 利用停止が解除された場合は元の表示名に戻る想定（退会は不可逆、利用停止は可逆という違いに注意）。
