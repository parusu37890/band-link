# 0002: 自由記入エリア欄のキーワード検索対象化

- 状態: 確定（2026-09-05）
- 関連: requirements.md 5章（募集投稿）・6章（検索・一覧・履歴）

## 背景

募集投稿の活動エリアは「都道府県を3つまで選択＋市区町村・駅などの自由記入」。6章のキーワード検索対象は「タイトルと本文」のみと明記されており、この自由記入欄が検索対象に含まれるか未記載だった。

## 決定

キーワード検索の対象に、タイトル・本文に加えて活動エリアの自由記入欄も含める。

## 理由

「下北沢で探したい」のような駅名・地域名での検索は実用上のニーズが高く、自由記入欄を検索対象外にすると使い勝手が落ちる。

## 影響

- 検索インデックス（全文検索用カラム or 別テーブル）は、タイトル・本文・エリア自由記入の3項目を対象に構築する。
- DB設計（6章保留事項）でのページング・全文検索方式の検討時に、この3項目を対象とすることを前提に含める。
