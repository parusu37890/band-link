# 0003: 投稿作成時のパート・ジャンル・活動スタンス選択数上限

- 状態: 確定（2026-09-05）
- 関連: requirements.md 5章（募集投稿）

## 背景

要件定義書は「パート・ジャンル・活動スタンスはそれぞれ1つ以上選ぶ」と下限のみ規定し、上限は未記載だった。検索側（6章）は複数選択可能だが、投稿側で無制限に選べると、一覧カードのタグ表示が縦に伸びすぎるなどUX上の懸念がある。

## 決定

投稿作成・編集時の選択数上限を以下に定める。

- パート: 最大5つ
- ジャンル: 最大3つ
- 活動スタンス: 最大1つ

## 理由

`band-link-preview.html`のカードUI（`.bl-tags`）を基準に、1投稿あたりのタグ数が多すぎると可読性が落ちるため上限を設ける。活動スタンスは性質上（趣味/プロ志向など）単一選択が自然。

## 影響

- DTOバリデーション（Bean Validation）で`@Size(min=1, max=N)`相当の制約を各項目に設定する。
- 上限値は初期値であり、実運用のフィードバック次第で調整可能とする。
