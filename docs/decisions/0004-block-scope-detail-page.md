# 0004: ブロック中の相手の投稿詳細ページへの直接アクセス

- 状態: 確定（2026-09-05）
- 関連: requirements.md 8章（ブロック・通報・管理）

## 背景

要件定義書は「ログイン中の募集一覧では双方に相手の投稿を表示しない」「公開情報はログアウトすれば閲覧できるため、ブロックを完全な閲覧禁止とは扱わない」と規定している。一覧非表示は明記されているが、投稿詳細ページへの直接URLアクセス（ログイン中）を遮断するかどうかは未記載だった。

## 決定

ブロックは一覧からの非表示のみとする。投稿詳細ページへの直接URLアクセスは、ログイン有無・ブロック関係の有無にかかわらず到達可能とする（従来の公開閲覧の扱いと同じ）。

## 理由

「公開情報はログアウトすれば見られるため完全閲覧禁止ではない」という既存の確定方針と整合させる。ログイン中だけ詳細ページを403にすると、ログアウトすれば同じ情報が見える中途半端な制限になり、実装・UXともに複雑化する割に効果が薄い。

## 影響

- 投稿詳細取得API（`GET /api/posts/{id}`相当）にブロック関係のチェックは不要。
- ブロックの実効範囲は「一覧・検索結果からの除外」に限定されることをUI文言（ヘルプ等）で誤解のないよう説明する余地がある（将来検討）。
