# 0007 本人退会時のデータ削除

## 状態

確定（2026-09-07）

## 決定

本人が退会した場合は、プロフィール、募集、投稿画像、会話、メッセージ、通知、ブロック、検索履歴、認証トークンを削除する。アカウント行も削除し、同じメールアドレスで新規登録できるようにする。

運営による利用停止は本人退会とは別扱いとし、アカウントと過去の会話を残す。停止中の送信者名は「利用停止中ユーザー」として表示し、停止解除は運営だけが行う。

## 理由

本人が自分で退会した場合は、テストや利用方針の変更後に同じメールアドレスでやり直せることを優先する。会話を残す要件は本人退会ではなく運営による利用停止の監査・継続性に適用する。

## 影響

- `POST /api/auth/withdraw` は論理退会ではなく、所有データの物理削除をトランザクションで行う。
- 既存の退会済み行を整理する旧SQLは、過去データの互換整理用として残す。新しい退会処理では使用しない。
