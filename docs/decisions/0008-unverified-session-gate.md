# 0008 登録直後の未確認セッションを確認画面に固定する

## 決定

登録直後に確認メールを送ったユーザーは、メールアドレスの確認が完了するまで本登録確認画面だけを利用できる状態にする。募集一覧、検索、プロフィール、メッセージ、通知、設定などの画面は表示せず、直接URLを開いた場合も `/verify-email` へ戻す。確認画面のヘッダーはロゴとログアウトだけにする。

確認メール内のワンタイムリンクが成功した後は、募集作成またはログインの導線を表示し、通常のナビゲーションを復帰させる。ログアウトは、メールを受け取れない場合に別アカウントへ切り替えるための唯一の退出手段として残す。

## 理由

未確認のまま通常画面を見せると、投稿やメッセージだけが後から拒否され、登録直後に利用できる範囲が分かりにくい。確認を最初の一手に限定することで、登録完了条件と利用開始の境界を明確にする。
