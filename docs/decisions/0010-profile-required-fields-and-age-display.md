# 0010 プロフィール必須項目と年齢表示の変更

## 決定

プロフィールを保存する際、担当パート、好きなジャンル、活動エリア、活動スタンス、経験年数、年齢、性別を必須とする。活動エリアは1つ以上3つまで、性別は「男」「女」の二択に限定する。

公開プロフィールと募集一覧では、年代ではなく入力した年齢を「○歳」と表示する。

## 理由

募集への応募判断に必要なプロフィール情報を登録時点で揃え、プロフィールごとの欠落を減らすため。年齢の表示方針は今回のプロダクト判断を優先し、入力値と表示値の対応を明確にする。

## 影響

既存アカウントがプロフィールを更新する場合も必須項目の入力が必要になる。入力制約はAPIと画面の両方で検証する。
