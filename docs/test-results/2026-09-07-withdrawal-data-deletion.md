# 本人退会と再登録の検証（2026-09-07）

## 決定

本人が退会した場合は、プロフィール・募集・画像・会話・メッセージ・通知・ブロック・検索履歴・認証トークンを削除し、同じメールアドレスで再登録できるようにする。運営による利用停止は会話を残す別処理とする。

- 指定されたローカルDBアカウントを確認し、確認トークンを含めて削除した。
- 削除後のDB検索で同メールアドレスの行が0件になったことを確認した。
- `./mvnw.cmd -B clean test`：**24件成功、失敗・エラー・スキップ0件**。
- `node --check src/main/resources/static/js/account.js`：成功。
- `git diff --check`：空白エラーなし。
- `AccountDeletionService` と同じ削除順序を一時ユーザーに対してPostgreSQLのトランザクション内で実行し、エラーなしでロールバックできることを確認。
